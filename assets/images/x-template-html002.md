## 📖 Overview

An interactive HTML5 visual canvas showcasing the **Taurus (♉) zodiac** as a futuristic sustainable stone sanctuary — built with pure HTML, local Tailwind CSS, and vanilla JavaScript.

**Key Features:**
- 🏰 Sustainable stone architecture theme (Tauria City)
- 🏦 Interactive city planner control panel (Treasury, Opera House, Citadel)
- 💰 Premium asset accumulation simulator
- ⚡ Provocation gauge trigger (Enraged Mode)
- 📱 Fully responsive (mobile-first)
- 🍪 GDPR & PDPA compliant Cookie Notice Banner

## 🚀 Deployment

This project is deployed automatically via **GitHub Actions** to GitHub Pages on every push to `main`.

### Manual Local Preview

Simply open `index.html` in a browser via a local server (required for `fetch()` component loading):

```bash
# Using Python
python -m http.server 8080

# Using Node.js npx
npx serve .
```

Then visit `http://localhost:8080`
