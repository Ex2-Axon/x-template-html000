## 📖 Overview

An interactive HTML5 visual canvas showcasing the **Gemini (♊) zodiac** as a futuristic communication metropolis — built with pure HTML, local Tailwind CSS, and vanilla JavaScript.

**Key Features:**
- 🌀 Interactive city core floating island visual animation
- 🗺️ Interactive city zones (Mercury Tower, Twin Plaza, Curiosity Lab, Indecisive Labyrinth)
- ⚖️ Gemini zodiac compatibility visa checker
- 🧠 Dual Personality Mode Toggle
- 📱 Fully responsive (mobile-first)
- 🍪 GDPR & PDPA compliant Cookie Notice Banner

## 🚀 Deployment

This project is deployed automatically via **GitHub Actions** to GitHub Pages on every push to `main`.

### Manual Local Preview

Simply open `index.html` in a browser via a local server (required for `fetch()` component loading):

```bash
# Using Python
python -m http.server 8080

# Using Node.js npx
npx serve .
```

Then visit `http://localhost:8080`
