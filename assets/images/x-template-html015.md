# Suanpan Abacus Learning Simulator (x-template-html015)

## คำอธิบาย

Suanpan Abacus Learning Simulator — เทมเพลตสำหรับเรียนรู้และทดลองใช้ลูกคิดจีนโบราณ (Suanpan) ที่มีระบบโต้ตอบและบทเรียนทีละขั้นตอน

## โครงสร้างไฟล์

- `index.html` — หน้าเว็บหลักที่มีแท็บสำหรับ Simualtor และ Guide
- `assets/tailwind.min.css` — ไฟล์ Tailwind CSS ที่คอมไพล์แล้ว
- `css/styles.css` — สไตล์เพิ่มเติมสำหรับลูกคิดและไอคอน

## วิธีใช้งาน

เปิดผ่าน local server เช่น:

```bash
python -m http.server 8000
```
